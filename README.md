# Elementor Pill Button

A lightweight, custom WordPress plugin that adds a modern, sleek pill-shaped button widget directly to your Elementor page builder toolkit.

---

## 🚀 Features

* **Seamless Elementor Integration:** Registers as a native widget within the Elementor editor.
* **Modern Pill Design:** Built with clean code for fully customizable, pill-shaped call-to-action buttons.
* **Lightweight Architecture:** Designed with zero external dependencies to keep your site fast and optimized.

---
